# Неправильный выбор

Интерактивная сюжетная игра с выбором и последствиями. Игрок проходит сюжет, делая выборы, которые влияют на состояние персонажа и дальнейший сюжет.

## Установка и запуск

1. Убедитесь, что у вас установлены Node.js и npm
2. Установите зависимости:
   ```bash
   npm install
   ```
   Зависимости устанавливаются автоматически при первом запуске проекта.
3. Запустите проект в режиме разработки:
   ```bash
   npm run dev
   ```
4. Откройте в браузере: http://localhost:5173

## Структура проекта

- `src/types.ts` - определения типов для игры
- `src/StoryEngine.ts` - основной движок игры
- `src/GameStateContext.tsx` - контекст состояния игры
- `src/story.ts` - данные сюжета (сцены и выборы)
- `src/components/` - компоненты интерфейса
  - `StatusBar.tsx` - отображение состояния персонажа
  - `StoryScreen.tsx` - отображение текущей сцены
  - `ChoiceButton.tsx` - кнопки выбора
 - `EndScreen.tsx` - экран завершения игры
- `src/App.tsx` - главный компонент приложения
- `src/styles.css` - стили приложения

## Добавление новых сцен

Для добавления новых сцен и ветвлений отредактируйте файл `src/story.ts`:

```typescript
{
  id: 'уникальный_идентификатор',
  text: 'Текст сцены, который видит игрок',
  choices: [
    {
      id: 'идентификатор_выбора',
      text: 'Текст кнопки выбора',
      nextSceneId: 'id_следующей_сцены',
      conditions: [ // опционально: условия для отображения выбора
        { type: 'has', property: 'drunk', value: false } // например, не пьяный
      ],
      effects: [ // опционально: изменения состояния после выбора
        { property: 'mood', value: 'confident' } // например, стать уверенным
      ],
      disabledText: 'Текст, показываемый если выбор недоступен' // опционально
    }
  ]
}
```
